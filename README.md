# Personal Assistant: Final Project (Тема 13)

Консольний бот-помічник для керування адресною книгою (книгою контактів). Це фінальна версія проекту, що реалізує розширений набір полів, повноцінне об'єктно-орієнтоване керування даними, інтерактивний пошук, автоматичну валідацію та інтеграцію з графічними діалоговими вікнами операційної системи для створення резервних копій.

## 🚀 Фінальний функціонал

- **Повноцінне ООП керування контактами**: Додавання, видалення, редагування та виведення даних.
- **Розширені поля даних**:
  - `Name` — обов'язкове ім'я контакту (захист від порожнього рядка).
  - `Phone` — декілька телефонних номерів для одного контакту (строга валідація на 10 цифр).
  - `Birthday` — дата народження (формат `ДД.ММ.РРРР` з перевіркою реальності календарних дат).
  - `Email` — електронна пошта (автоматична валідація формату за регулярним виразом).
  - `Address` — фізична адреса проживання контакту.
- **Система нотаток (Notes)**: Можливість додавати текстові замітки, коментарі або теги (наприклад `#Like_apple`) до будь-якого контакту.
- **Інтелектуальний пошук (`search`)**: Пошук контактів за частковим збігом (підрядком) в імені, номерах телефонів або нотатках.
- **Покращений інтерфейс (`all`)**: Виведення всієї бази контактів на екран у вигляді красивої, структурованої текстової таблиці з автоматичним вирівнюванням колонок.
- **Двостадійне збереження даних (`pickle`)**:
  1. **Локальне автозбереження**: База даних автоматично оновлюється у файлі `addressbook.pkl` у папці проекту після кожної успішної команди додавання чи зміни даних.
  2. **Графічний бекап на ЖД**: При введенні команд виходу (`exit` / `close`), бот викликає системне графічне вікно Windows із запитом. Якщо користувач бажає, відкривається провідник папок для вибору будь-якого місця на комп'ютері чи флешці для збереження резервної копії.

## 🛠️ Структура проекту

- `fields.py` — класи полів `Field`, `Name`, `Phone`, `Birthday`, `Email`, `Address` (із вбудованою логікою валідації).
- `record.py` — клас `Record` для об'єднання всіх полів конкретної особи, керування телефонами та нотатками.
- `address_book.py` — клас `AddressBook` на базі `UserDict` з логікою пошуку за підрядком, розрахунку найближчих свят та генерації табличного виводу.
- `errors.py` — декоратор `@input_error` для багаторівневого перехоплення помилок користувача.
- `main.py` — консольний інтерфейс користувача (CLI) та інтеграція з графічними діалогами `tkinter`.

## 📦 Встановлення та запуск

Проект використовує лише вбудовані бібліотеки Python, тому додаткові зовнішні залежності не потрібні.

### 1. Налаштування віртуального оточення (`venv`)

Відкрийте термінал у папці проекту та виконайте:

**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Для macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3. Запуск програми
```bash
python main.py
```

## 🕹️ Доступні команди бота

Команди в терміналі вводяться через пробіл та не чутливі до регістру символів:


| Команда | Аргументи | Опис | Приклад |
| :--- | :--- | :--- | :--- |
| `hello` | - | Привітання з ботом | `hello` |
| `add` | `[ім'я]` `[телефон]` | Додає контакт або новий номер телефону до наявного | `add John 1234567890` |
| `change` | `[ім'я]` `[старий_тел]` `[новий_тел]` | Замінює старий номер телефону на новий | `change John 1234567890 5555555555` |
| `phone` | `[ім'я]` | Показує всі номери телефонів для вказаного контакту | `phone John` |
| `add-birthday` | `[ім'я]` `[дата]` | Додає або перезаписує день народження | `add-birthday John 01.05.2000` |
| `show-birthday` | `[ім'я]` | Показує дату народження конкретного контакту | `show-birthday John` |
| `birthdays` | - | Список контактів, кого треба привітати на наступному тижні | `birthdays` |
| `send-email` | - | Створює CLI-конверт із привітанням для іменинників наступного тижня | `send-email` |
| `add-email` | `[ім'я]` `[пошта]` | Додає email з перевіркою формату | `add-email John john@gmail.com` |
| `add-address` | `[ім'я]` `[адреса]` | Додає фізичну адресу контакту (підтримує пробіли) | `add-address John Kyiv, Ukraine` |
| `add-note` | `[ім'я]` `[текст]` | Додає нотатку або текстовий тег до контакту | `add-note John #Like_apple` |
| `search` | `[текст]` | Шукає збіги за частиною імені, телефону чи нотаток | `search Natalia` або `search 78978` |
| `all` | - | Виводить усю адресну книгу у вигляді красивої таблиці | `all` |
| `delete` | `[ім'я]` | Повністю видаляє контакт із книги | `delete John` |
| `exit` / `close` | - | Автозберігає базу та відкриває системне вікно для бекапу | `exit` |

## 🛡️ Приклади обробки помилок та валідації

Якщо ви введете некоректні дані, система захистить базу від збоїв та підкаже рішення:
* `add John 123` ➡️ `Error: Phone number must contain exactly 10 digits.`
* `add-birthday John 32.02.2024` ➡️ `Error: Invalid date format. Use DD.MM.YYYY`
* `add-email John john@gamilcomkkk` ➡️ `Error: Invalid email format. Example: user@example.com`
* `phone Unknown` ➡️ `Error: Contact 'Unknown' not found.`
